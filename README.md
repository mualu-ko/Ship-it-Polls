# Ship It Polls (Frontend Demo) 🗳️

A lightweight, **frontend-only polling application** using **Local Storage**.

**Ship It Polls** is a modern web application that allows users to create, vote on, and track polls. This version is designed for instant deployment and testing **without requiring a backend server**—all data is stored directly in your browser.

## ✨ Features

- **Create Polls** – Add a poll question and multiple options.
- **Instant Voting** – Votes are recorded instantly with simulated network latency.
- **Live Results** – Dynamic progress bars visualize vote percentages.
- **Local Persistence** – Polls persist using Local Storage, even after refresh.
- **Duplicate Vote Prevention** – Users cannot vote twice on the same poll (per browser session).
- **Responsive Design** – Fully responsive UI built with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Styling:** Tailwind CSS  
- **Persistence:** Local Storage (JSON)  
- **State Management:** React Hooks (`useState`, `useEffect`)
